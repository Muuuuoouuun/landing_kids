# 클래스인(ClassIn) 쇼릴 (22초 · 60fps)

이미지·동영상 소스 없이 **코드만으로** 그리는 픽셀 아트 쇼릴입니다.
장면은 480×270 설계 좌표로 짜고, 실제로는 1.2배인 576×324 픽셀 캔버스에 매 프레임을 그립니다
(원·선·디더는 촘촘하게, 폰트·스프라이트는 정수 픽셀로). ffmpeg 로 최근접 4배 확대 → 면적 평균으로
1920×1080 · 60fps 영상을 뽑습니다. 테마 색은 파스텔 연두(`#C6EBA4`, `gfx.mjs` 의 `C.theme*`).
사운드트랙(8비트 칩튠)과 효과음도 전부 합성합니다.

상호작용 순간마다 "정답!" "딸깍!" "반짝!" 같은 만화식 터짐 효과가 붙습니다.

결과물: `public/showreel/classin-showreel.mp4` (H.264/AAC), `.webm` (VP9/Opus), `poster.png`

## 구성 (120BPM · 1마디 = 2초)

| 시간 | 장면 | 내용 |
| --- | --- | --- |
| 0–2s | BOOT | CRT 전원 → 연필·자·책·주판·플라스크·돋보기·지구본이 궤도로, 로고 낙하 |
| 2–16s | LIVE | 실시간 온라인 수업 한 편. 칠판 + 선생님·학생 화상 타일(집 셋 + 학원 교실 하나) + 도구 막대가 이어지고, 칠판 활동만 지우개로 쓱 바뀜 |
| 2–4s | └ 타이머 퀴즈 | 원형 타이머 5→0, 객관식 4지선다, 투표 실시간 집계 → 정답률 75% |
| 4–6s | └ 개인 칠판 | 아이 넷이 각자 칠판에 CAT 손글씨 → 선생님 '참잘했어요' 도장 |
| 6–8s | └ 랜덤 선택 · 트로피 | 점점 느려지는 룰렛 → 민준 당첨 → 트로피가 타일로 날아감 |
| 8–10s | └ 가상 실험 | 전기 회로: 서연이 전선을 끌어 연결 → 전구 반짝, 민준이 스위치를 껐다 켬 |
| 10–14s | └ AI 스피킹 | ① AI 미니가 "I like cats." 읽기 → ② 지우가 따라 읽기(녹음) → ③ AI 발음 채점 95점 |
| 14–16s | └ 정리 | "실시간 온라인 수업도 교실처럼 생생하게!" + 기능 7개 |
| 16–18s | PLAYER SELECT | 5세·7세·초3, 나이·수준별 맞춤 |
| 18–20s | PARENT | 부모님 폰으로 오는 오늘의 리포트 |
| 20–22s | FINALE | 로고 + "놀면서 배우는 인터랙티브 수업" + 무료 체험 수업 신청 |

## 명령

```bash
npm run showreel          # 영상 + 포스터 렌더 (약 2분)
npm run showreel:sheet    # 30프레임 간격 컨택트 시트 → showreel/out/
node showreel/render.mjs --stills 0,300,900   # 특정 프레임 PNG
npm run showreel:font     # 텍스트를 바꿨다면 폰트 서브셋 재생성
```

ffmpeg 가 PATH 에 있어야 합니다.

## 파일

- `scenes.mjs` — 타임라인, 장면, 효과음 큐(`SFX`). 문구·타이밍은 여기서 수정
- `art.mjs` — 마스코트 "미니", 아이들, 커서·트로피, 이펙트(파티클·아이리스·와이프·터짐 말풍선)
- `tools.mjs` — 픽셀 수업 도구(연필·크레파스·자·책·주판·플라스크·돋보기·지구본·로켓 등)
- `gfx.mjs` — 의존성 없는 픽셀 래스터라이저 + 비트맵 폰트 렌더
- `audio.mjs` — 칩튠 합성(펄스·삼각파·노이즈)과 효과음
- `fonts.json` — 갈무리(Galmuri, OFL-1.1) 픽셀 폰트 중 사용 글자만 추린 것
